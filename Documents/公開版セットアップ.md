# 公開版セットアップ

この文書は、既存のJitsi Meet環境に `jitsi-meet-ai` を追加する担当者向けです。すべてのコマンドを一括実行する手順ではありません。対象サーバーの構成と設定ファイルを確認して進めてください。

## 前提条件

Jitsi MeetのHTTPSと会議音声が動作し、Nginx・Prosody・Jicofo・JVBが構成済みであることが前提です。管理者はSSHとsudoを利用できる必要があります。Python 3.10以上、ffmpeg、録画を使う場合はJibriと対応するChrome・ChromeDriverが必要です。

検証構成の版と確認範囲は[構成・保守手順](構成・保守手順.md)と[検証記録](検証記録.md)を参照してください。設定ファイルやサービスの配置はDebian/Ubuntu系を想定しています。

## 対象ドメイン

サーバーで実行する構成スクリプトには、対象のドメインを明示します。次の設定例を自分のドメインに置き換えてください。

```bash
export JITSI_DOMAIN=your-meet.example.org
```

`meet.example.com` のまま、未設定、またはパスを含む値の場合は構成処理を停止します。`.env.example` は設定項目の例であり、自動では読み込みません。

稼働時のAPIサービスは、配備処理が生成する `/etc/jitsi-ai/environment` からドメインとOriginを読み込みます。ドメインを変更するときはNginx、Prosody、証明書などのJitsi本体側の変更も必要です。

## 管理者の初期設定

ローカルで次を実行します。パスワードは表示せずに入力し、ハッシュだけを生成します。管理画面のユーザー名は `ubuntu` です。SSHアカウントとは独立した認証です。

```powershell
python ops/init-admin.py --output .local/admin-seed.json
```

生成したファイルを対象サーバーの `/tmp/jitsi-ai-admin-seed.json` へ転送し、所有者と権限を確認してください。ファイルはGitに追加しません。既存の管理者設定がある環境では初期化ファイルは使用せず、設定を保持します。

## ソースと音声の配置

公開リポジトリには音声バイナリを含めていません。[音声の生成方法](../assets/announcements/README.md)に従い、必要なら音声を用意してから次を実行します。

```powershell
python ops/package.py
```

配布物 `.local/jitsi-ai.tgz` を対象サーバーの `/tmp/jitsi-ai.tgz` へ転送し、次のように展開します。プログラムの配備先は `/opt/jitsi-ai` です。公開リポジトリ名と配備ディレクトリ名は異なります。

```bash
sudo mkdir -p /opt/jitsi-ai
sudo tar -xzf /tmp/jitsi-ai.tgz -C /opt/jitsi-ai --no-same-owner
```

## 構成する項目

対象サーバーの設定・会議データ・録画をバックアップしてから、次のスクリプトを確認し、必要な構成に適用します。

| スクリプト | 対象 |
| --- | --- |
| `ops/install-recording.sh` | Jibri、Chrome・ChromeDriver等の導入補助 |
| `ops/configure-recording.py` | 録画用XMPP認証、Jicofo、Jibri、Web設定 |
| `ops/deploy.sh` | APIサービス、日本語Web画面、Nginx中継、音声案内 |
| `ops/install-native-proxy.sh` | 固定コミットの公式Opusプロキシのビルド |
| `ops/configure-native.py` | Prosody・Jicofo・JVBの字幕・通訳連携 |

管理者設定のシード、必要なサービスユーザー、録画ディレクトリ、Python仮想環境など、各スクリプトが参照する前提を確認してください。再起動を含むため、会議がない保守時間に実施します。sudoが環境変数を引き継がない場合は、rootのシェルで対象ドメインを設定してください。

構成後はNginx・Prosodyの設定確認、サービスの稼働、マイク音声、字幕・通訳、短い録画、保存後の議事録作成を確認します。管理画面は自分のドメインの `/ai/admin` です。APIキーは管理画面から設定します。

## SSH補助スクリプト

`ops/remote.py` を使う場合は、ローカルにParamikoを導入してください。`JITSI_SSH_HOST`、`JITSI_SSH_USER`、`JITSI_SSH_FINGERPRINT`、`JITSI_SSH_PASSWORD` を自分の環境変数に設定します。ホスト鍵の指紋は別の信頼できる経路で確認してください。

このリポジトリには接続先や秘密情報の既定値を用意していません。秘密情報をコマンド履歴、共有ログ、Gitへ保存しないよう管理してください。
