# Jitsi Meet 操作手順書

公開版の文書では `meet.example.com` を設定例に使用しています。リンクと接続先は、自分が構築した環境のドメインへ読み替えてください。

対象：`meet.example.com` のテスト環境。更新日：2026年11月5日。

会議への参加にはWebブラウザーまたは公式Jitsi Meetアプリを使用します。日本語・英語・中国語・韓国語・ベトナム語の字幕と音声通訳を利用できます。通訳は参加時にはオフです。

## 利用前の準備

ヘッドセットを接続し、マイクとスピーカーを確認してください。スマートフォンでは公式Jitsi Meetアプリを最新版に更新してください。

AI会議では参加者の音声をOpenAIへ送信します。主催者は参加者へ事前に説明してください。録画の自動解析を有効にした場合は、録画音声も送信します。API利用料金は管理者が設定したキーのプロジェクトに発生します。

## APIキーとモデルの設定

1. [管理画面](https://meet.example.com/ai/admin)を開きます。
2. サインイン画面でユーザー名 `ubuntu` と、別途共有された管理用パスワードを入力し、「サインイン」を押します。従来と同じパスワードを使用します。パスワードはこの手順書には記載していません。
3. 新規設定や変更の場合は「新しいAPIキー」に入力し、「設定を保存」を押します。空欄で保存した場合は、現在のキーを維持します。
4. 「API接続を確認」を押します。認証とモデル一覧の取得結果を確認します。この操作では音声認識や翻訳の実動作までは確認しません。
5. 「モデル候補を取得」を押し、用途ごとにモデルを選びます。
6. 必要な項目を変更し、「設定を保存」を押します。

| 設定項目 | 用途 | 初期値 |
| --- | --- | --- |
| 会議中の文字起こしモデル | 発言の自動認識と原文字幕 | `gpt-transcribe` |
| 録画の文字起こしモデル | 保存した録画の音声認識 | `gpt-transcribe` |
| 字幕翻訳モデル | 原文字幕を選択した言語に翻訳 | `gpt-4o-mini` |
| 音声通訳モデル | 会議中の発言を通訳音声に変換 | `gpt-realtime-translate` |
| 議事録モデル | 概要、決定事項、タスクを作成 | `gpt-5-mini` |

管理画面は、設定済みキーで取得したOpenAIのモデルを用途別に表示します。用途によって対応するAPIが異なるため、選べるモデルも異なります。音声通訳は専用API対応モデルに限ります。確認時点でこのキーから取得できた対応モデルは `gpt-realtime-translate` の1種類でした。

一覧にあるモデルでも、残高や個別の利用制限によって実行できない場合があります。初期値以外の全候補について、実際の音声・翻訳品質を検証したわけではありません。古い音声認識モデルには終了予定を表示します。終了日は[OpenAIの音声認識ガイド](https://developers.openai.com/api/docs/guides/speech-to-text)で確認してください。

会議中の文字起こし・字幕翻訳・音声通訳モデルやキーを変更すると、AI接続が再接続されます。変更は会議の前に行ってください。保存済みのキーは画面に再表示しません。削除する場合は「キーを削除」を使用します。

## 管理者画面からのサインアウト

設定や確認を終えたら、管理者画面の右上にある「サインアウト」を押してください。サインイン画面へ戻り、「サインアウトしました。」と表示されます。管理者画面をもう一度開くには、パスワードの入力が必要です。

サインインの有効期間は8時間です。期限が切れた場合も、再度サインインしてください。サインアウトしても、保存済みAPIキー、モデル設定、会議、録画、議事録は削除されません。開催中の会議も継続します。

## AI会議の作成

1. 管理画面の「AI会議を作成」で会議名を入力します。
2. 「会議と招待リンクを作成」を押します。
3. 「参加リンク（Web・公式アプリ共通）」を参加者へ共有します。
4. 主催者は「主催者として参加」から会議画面を開きます。
5. 議事録を参加者へ配布する場合は「参加者の議事録画面」のリンクも共有します。

主催者リンクでは録画の取得やAI処理の終了ができます。参加者には配布しないでください。

AI利用と記録画面の招待リンクの有効期間は、会議を作成してから24時間です。Jitsiの会議参加URL自体は通常の会議URLであり、24時間後に会議への参加まで禁止する設定にはしていません。有効期限後の記録は管理画面から取得できます。

## Webからの参加

参加リンクを開き、表示名を入力して「ミーティングに参加」を押してください。主催者の会議画面では、表示名を入力して「ブラウザーで参加」を押します。ブラウザーからマイクの許可を求められたら許可してください。

主催者が先に入室してください。この環境は匿名参加の構成で、最初の参加者にJitsiのモデレーター権限が付与されます。記録画面の主催者権限と、会議内のモデレーター権限は別です。

## iPhone・Androidからの参加

1. 公式Jitsi Meetアプリを開きます。
2. 管理者から届いた参加リンクを、サーバー名を含むURL全体で入力します。自動生成された `ai-` で始まる会議名だけを入力すると、別のサーバーに接続する場合があります。
3. 表示名を入力し、マイクの利用を許可して参加します。
4. 会議内の追加メニューから「音声通訳」または「字幕」を開きます。

主催者の会議画面には「iPhoneアプリを開く」「Androidアプリを開く」もあります。リンクで起動できない場合は、上記の方法で参加リンクをアプリに入力してください。

2026年11月4日の確認では、iPhoneに音声通訳・字幕の項目が表示されたとの報告がありました。iPhoneでの実際の音声再生・字幕表示と、Android実機での確認は未完了です。アプリの版によって表示名や配置が異なる場合があります。

## 音声通訳

1. 会議の「詳細な操作」または追加メニューから「音声通訳」を開きます。
2. 聞きたい言語を選択します。日本語は「日本語」、英語は「English」、中国語は「中文」、韓国語は「한국어」、ベトナム語は「Tiếng Việt」です。
3. 終了するときは同じ画面で「オフ」を選択します。

発言する言語の指定は不要です。サーバーが音声を受け取り、入力言語を自動認識します。通訳音声を受信している間は原音の音量が下がります。選ぶ言語は参加者ごとに異なっていて構いません。

参加時の通訳言語は未選択で、音声通訳は始まりません。字幕や議事録用の文字起こしは、音声通訳とは別に動作します。通訳の遅延や認識結果は、発言内容、回線、APIの応答によって変わります。

会議のモデレーターが会議全体の音声通訳を禁止した場合は利用できません。Web版では「設定」のモデレーター項目で許可状態を確認できます。

## 字幕

会議の追加メニューで「字幕」を開きます。原文を表示する場合は原文の項目を選び、翻訳する場合は字幕パネルの言語欄から表示言語を選択してください。Web版の言語欄には英語表記が残る項目があります。

音声通訳と字幕はそれぞれ選択します。通訳の言語を選んだだけでは、字幕パネルは開きません。

## 録画

1. 録画とAI解析について参加者へ説明します。
2. 主催者の会議画面で「録画を開始」を押し、確認します。公式アプリや通常のJitsi画面では会議内の「録画」を使用します。
3. 「サーバーに録画中」または会議内の録画表示を確認します。
4. 終了するときは「録画を停止」を押します。
5. 保存と解析が完了するまで待ち、会議画面または管理画面の「会議の記録」で状態を確認します。

録画は720p、1秒あたり15フレームで、同時に1件です。別の会議が録画中の場合は開始できません。保存する音声は会議の原音です。参加者ごとの通訳音声は録画に重ねません。

録画・文字起こし・配信の開始と停止の音声案内は、Web版だけ日本語にしています。公式アプリはアプリ標準の音声案内を使用します。会議内の録画表示や通知も確認してください。

会議に自動参加する音声案内ボットは停止しました。以前の設定で参加中の場合は、一度退出して再参加してください。Web版の音声が以前のままの場合は、ブラウザーを強制再読み込みしてください。

## 議事録とタスク

「録画終了後・会議終了後に議事録とタスクを自動作成する」が有効なら、録画保存後に解析を開始します。会議中の文字起こしがある場合は、最後の参加者が退出した後にも議事録を作成します。

録画を使わずに作成する場合は、主催者の会議画面で「議事録を作成」を押してください。自動作成が無効でも手動で依頼できます。解析を停止して保存した録画は、管理画面の「解析を開始」から処理できます。

| 状態 | 対応 |
| --- | --- |
| 録画保存済み・解析停止 | 自動解析が無効です。必要なら管理者が解析を開始します。 |
| 処理待ち・解析中 | 処理が終わるまで待ちます。画面は定期的に更新されます。 |
| APIキー設定待ち | 管理者がAPIキーを設定します。 |
| 完了 | ファイルを取得し、内容を確認します。 |
| エラー | 表示内容を確認し、設定の修正後に管理画面で「再実行」を押します。 |

取得できるファイルは録画MP4、文字起こしTXT、議事録Markdown、タスクCSVです。録画は主催者と管理者が取得できます。参加者の記録画面では文字起こし・議事録・タスクを取得できます。

議事録には概要、決定事項、主な議論、タスク、確認が必要な点を記載します。タスクには担当者、期限、根拠となる発言を付けます。担当者や期限が不明な場合は「未定」です。AIが作成した下書きとして、原音や文字起こしと照合してください。

## 会議の終了

会議を終えるときはJitsiの退出・終了操作を使用してください。主催者の「AI処理を終了して議事録を作成」は、音声のAI処理を止めて議事録を作成する操作です。公式アプリで参加している人を会議から退出させる操作ではありません。

録画、文字起こし、議事録の自動削除は設定していません。必要な記録をダウンロードし、保存期間とサーバー上の削除は管理者が管理してください。

## 利用量の設定

初期値では、文字起こしは1接続あたり最大4音声ソース、音声通訳はサーバー全体で最大4発言者の接続に制限しています。上限を超える会議のAI処理は保証していません。

1会議の累計音声時間は初期値120分です。文字起こしと音声通訳へ中継した音声を、参加者・処理経路ごとに合算します。1人の発言を両方の経路へ送ると両方の時間を数えるため、会議の経過時間とは一致しません。この上限はOpenAI側の請求額の上限ではありません。

通訳先の言語が増えるとAPIの利用量も増えます。料金とプロジェクトの利用状況は[OpenAIの管理画面](https://platform.openai.com/usage)で確認してください。

## 問題があるとき

| 症状 | 確認すること |
| --- | --- |
| 管理画面に入れない | 管理用のユーザー名・パスワードを確認します。APIキーはログイン用パスワードではありません。 |
| モデル候補を取得できない | キーを保存してAPI接続を確認し、候補を再取得します。 |
| 401・403・404・429のAPIエラー | キー、モデルの利用権限、モデル名、利用上限・残高を確認します。 |
| アプリに音声通訳が表示されない | アプリの更新、接続先URL、AI会議の有効期間、モデレーターの許可を確認します。 |
| 通訳が聞こえない | 聞きたい言語の選択、相手のマイク、端末音量、ヘッドセット、API利用量を確認します。 |
| 音が回り込む | ヘッドセットを使用します。同じ場所で複数端末のマイクとスピーカーを同時に有効にしないでください。 |
| 録画を開始できない | 会議内のモデレーター権限と、他の会議の録画状況を確認します。 |
| 記録画面のリンクが無効 | 作成から24時間を超えていないか確認します。期限後は管理者が管理画面から取得します。 |

## 参照先

この手順書の画面名・権限・制限値は、この環境に追加した管理画面とサービスの実装に基づきます。会議の音声中継は[Jitsiの公式手順](https://jitsi.github.io/handbook/docs/devops-guide/transcription/)、音声通訳は[OpenAIの公式ガイド](https://developers.openai.com/api/docs/guides/realtime-translation)を参照しています。
